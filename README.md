# Итоги и цена советской модернизации

Учебный сайт: данные и графики по СССР (1928–1940-е гг.), хроника и тест с интерактивными заданиями. Ответы студентов с оценкой от 2 до 5 попадают в Google Таблицу преподавателя.

## Структура

```
index.html            — страница сайта
css/style.css         — оформление
js/data.js            — все цифры и источники (правьте здесь)
js/charts.js          — графики на чистом SVG
js/main.js            — отрисовка графиков и плиток
js/interactive.js     — ползунки и кнопки в разделах с данными
js/test.js            — тест: задания, контроль уходов со страницы, отправка
js/config.js          — адрес скрипта Google и настройки теста
apps-script/Code.gs   — скрипт для Google Таблицы: ключ ответов, баллы, оценка, штраф
                        (в публичный репозиторий НЕ выгружается — хранится у преподавателя)
```

## Как работает тест

1. Задания открываются только после ввода фамилии, имени и группы.
2. После начала теста считаются уходы со страницы: переключение вкладки или приложения, сворачивание окна, перезагрузка. Каждые 2 ухода снижают итоговую оценку на 1 (не ниже «2»).
3. Ответы сохраняются в браузере студента: при случайной перезагрузке они не пропадут (но уход будет засчитан).
4. После отправки скрипт сам считает баллы (из 33) и оценку и дописывает строку в лист «Ответы». Повторно отправить с того же браузера нельзя.
5. Два развёрнутых ответа (задания 24 и 25) в автоматическую оценку не входят — они записываются в таблицу для ручной проверки.

**Шкала оценок** (меняется в `Code.gs`, `GRADE_SCALE`): 29–33 балла — «5», 23–28 — «4», 17–22 — «3», меньше 17 — «2».
**Штраф за уходы** — `EXITS_PER_PENALTY`, `PENALTY`, `PENALTY_ON` в `Code.gs`. Если меняете число уходов, поменяйте и `EXITS_PER_PENALTY` в `js/config.js` (это число показывается студенту).

## Google Таблица (если настраиваете заново)

1. Создайте Google Таблицу → **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` текстом из `apps-script/Code.gs`, сохраните.
3. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение». «Запуск от имени»: **Я**; «У кого есть доступ»: **Все**. Разрешите доступ к таблице.
4. Скопируйте URL веб-приложения (заканчивается на `/exec`) в `js/config.js` → `SCRIPT_URL`.
5. Если потом меняете код скрипта: **Начать развёртывание → Управление развёртываниями → Изменить → Версия: новая версия**. URL при этом не меняется.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `soviet-modernization`.
2. **Add file → Upload files** — перетащите все файлы и папки, нажмите **Commit changes**.
3. **Settings → Pages** → *Deploy from a branch*, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://<логин>.github.io/soviet-modernization/`.
