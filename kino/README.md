# Кино и общество — раздел /kino/

Адрес: https://historia-sssr.github.io/kino/

Два видео («Как Сталин изменил советское кино» — в двух частях из-за лимита GitHub 100 МБ на файл; «О чём на самом деле любимые советские фильмы») и два теста по 20 вопросов.

## Файлы

```
index.html          — страница
kino.css            — оформление (адаптировано под телефоны, включая iPhone)
js/config.js        — адрес Google Apps Script (SCRIPT_URL)
js/questions.js     — тексты вопросов и фрагменты видео (без правильных ответов)
js/app.js           — регистрация, тест, счётчик уходов, отправка
video/              — видео и обложки
```

Ключ ответов хранится только в Google Apps Script (`Code.gs` у преподавателя), в репозиторий не выкладывается.

## Как работает тест

1. Тест открывается только после ввода ФИО и группы.
2. 20 вопросов: с выбором ответа (оценка 2–5 ставится автоматически) и открытые (проверяет преподаватель).
   Шкала (в `Code.gs`, `GRADE_SCALE`): от 85 % верных — «5», от 65 % — «4», от 45 % — «3», ниже — «2».
3. Считаются уходы со страницы (переключение вкладки или приложения, сворачивание). На оценку они не влияют, а только записываются в таблицу вместе со временем ухода.
4. Ответы сохраняются в браузере студента. Отправить тест можно один раз.
5. Каждый тест пишется на свой лист таблицы. В столбце «Оценка преподавателя» можно выставить итог с учётом открытых ответов.

## Подключение Google Таблицы

1. Создайте Google Таблицу → **Расширения → Apps Script**.
2. Замените содержимое `Code.gs` текстом из файла `Code.gs` (выдан преподавателю отдельно), сохраните.
3. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение». «Запуск от имени»: **Я**; «У кого есть доступ»: **Все**. Разрешите доступ.
4. Скопируйте URL (заканчивается на `/exec`) в `js/config.js` → `SCRIPT_URL`.

Пока `SCRIPT_URL` пустой, тест работает в демо-режиме: ответы никуда не отправляются.
